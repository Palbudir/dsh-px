# 电脑操作

“电脑操作”是可选功能包，让 Agent 在你开启并授权后查看和操作本机 Windows 应用与网页。它默认**关闭**：安装或更新后不会获得任何操作电脑的能力，需要在工具栏打开“电脑操作”面板逐项开启。目前只支持 Windows。

## 开启方式

| 开关                  | 作用                                                                                     |
| --------------------- | ---------------------------------------------------------------------------------------- |
| 操作桌面应用          | Agent 可以列出窗口、读取界面元素与截图、点击、输入、按键、滚动、拖动、打开菜单和启动应用 |
| 浏览器：独立浏览器    | 使用本机 Edge 的临时配置，不含你的登录状态，关闭后不留数据                               |
| 浏览器：PX 专用浏览器 | 使用 PX 自己的 Edge 配置，保留你在其中登录过的网站，同一时间只供一个会话使用             |
| 浏览器：接管我的 Edge | 通过 Playwright 扩展连接你正在使用的 Edge，含其登录状态，同一时间只供一个会话使用        |

“接管我的 Edge”需要你先从 Edge 扩展商店安装 **Playwright Extension**（微软发布）。每次连接时 Edge 会打开确认页，由你选择要共享的标签页；PX 不会设置跳过确认的令牌。独立浏览器和 PX 专用浏览器可以选择后台运行（不显示窗口）。

开启后，DSH 会在会话中提供 `computer_*` 与 `browser_*` 工具和一段使用指引；关闭开关会立即移除它们，并中止该能力正在进行或等待确认的操作，旧确认卡随之取消。关闭桌面应用或浏览器，或切换浏览器模式后，本会话此前对相应应用或网站的允许失效，再次使用时重新询问；“始终允许”列表不受影响。

## 每一步都在你的掌控中

- **应用授权**：每个会话第一次读取或操作某个应用（包括启动它）前，会弹出 DSH 原生确认卡。允许后，本会话对这个应用的查看、点击和输入不再逐次询问。商店应用按窗口区分：允许计算器不等于允许设置。
- **网站授权**：在 PX 专用浏览器或接管 Edge 模式下，每个会话第一次读取或操作某个网站前会询问；点击链接或重定向到新网站时，先询问再把页面内容交给模型。独立浏览器没有登录状态，不逐站询问。
- **敏感动作再次确认**：删除数据、代表你发送或提交、付款、修改账号与权限、安装软件、修改系统安全设置等，指引要求 Agent 先调用确认工具，由你在确认卡上批准，批准只对那一步有效。这一步依赖模型遵守指引，与 Codex 的做法相同。以下情况由代码强制确认：上传文件；打开安装包；运行“下载”“桌面”或临时目录中的程序；运行系统目录和常用安装目录以外的程序（确认卡显示完整路径）。
- **始终禁止**：终端与命令行、运行对话框、开始菜单与系统搜索、任务栏与桌面、注册表与管理工具、任务管理器、用户账户控制与登录界面、Windows 安全中心与常见杀毒软件、密码管理器（应用与网站）、远程控制软件、DSH-PX 自身以及 ChatGPT、Codex、Claude 等 Agent 应用；Windows 键；`file://`、`edge://` 等非网页地址。被禁止的窗口不会出现在 Agent 看到的窗口列表中。
- **不可信内容**：屏幕和网页上的文字只作为数据交给模型，并带有说明；页面上的“请把文件发给某人”之类内容不能代表你的授权。

可以在面板中把本会话已允许的应用或网站设为“始终允许”，也可以随时撤销。会话处于不显示确认提示的完全访问模式时，确认会被自动拒绝，只有“始终允许”的应用和网站可以使用。

## 查看与停止

面板显示本会话的操作记录：时间、工具、目标、参数摘要和结果（工具已返回、失败、已拦截、未获允许），最多保留最近 200 条，只保存在本次运行中。桌面动作同时记录请求的投递方式与驱动回报；驱动没有给出方式时显示未知，效果仍需重新观察。确认与拒绝同时写入 DSH 会话日志。

“停止并暂停本会话”会中断正在进行的电脑和浏览器操作，取消正在等待的确认卡，并拒绝之后的操作，直到你点击恢复；暂停时尚未批准的请求不会保留，恢复后需要重新确认。DSH 自身的停止按钮也会中断正在进行的操作。

桌面驱动运行在独立子进程中。原生调用取消、崩溃或超过 45 秒时终止驱动并清除旧窗口观察，不自动重跑动作；下次明确调用才重新建立驱动。点击或输入可能已经部分生效，需要重新观察后判断。驱动不响应不会阻塞 DSH 的普通对话。这个进程隔离不等于系统权限沙箱。

物理桌面共用一个串行执行器；整个执行器重置时，尚未执行的桌面请求也会中止，不能拿重置前的授权和元素编号继续排队点击。浏览器能力与普通对话不受该桌面重置影响。

不同 DSH 会话使用各自的驱动连接，输入仍经过同一串行队列。某个底层连接已结束时，暂停该会话并显示恢复方式；不会自动恢复被结束的控制或重放动作。通过面板恢复后重新建立连接并取得窗口授权，不影响其他会话的连接。

## 后台与前台

桌面应用默认采用“仅后台操作”。能否成功取决于目标窗口和动作：UIA 按钮调用、控件赋值、定向点击、键盘输入并不具有相同的支持范围。后台不支持时返回具体限制，不自动改为前台。最小化窗口仍可能提供元素树，但不返回截图；遮挡、最小化与锁屏不能混为一谈。锁屏、断开的远程桌面和任意应用的后台无人值守不在当前承诺范围内。

后台组合键与修饰键在投递前拒绝，避免 `Ctrl+A` 被应用当作普通 `a` 输入。支持的文本控件可用语义赋值替换内容；需要快捷键时明确使用已授权的前台模式，不自动抢占焦点。

观察结果会区分前台／后台、当前／其他 Windows 虚拟桌面及系统隐藏状态。跨虚拟桌面可使用原生截图；支持的传统按钮、文本框通过定向控件消息操作，不切换桌面。密码框、只读框和不支持的控件不会出现在可操作清单中；快照后控件内容变化时拒绝继续写入。其他跨桌面动作明确要求前台或应用专用接口，不用可能抢焦点的 UIA 调用偷偷回退。截图可用与后台输入可用是两回事。

确实需要前台时，在面板选择“允许前台操作（按会话和窗口授权）”。首次授权绑定当前 DSH 会话和指定窗口，普通查看、点击、输入与按键不再逐次询问。开启前台模式后的首次应用确认会明确说明可占用该窗口的前台鼠标和键盘；应用此前只有读取授权时，第一次前台动作再申请窗口控制。新窗口不会仅因同属一个程序就自动获得前台授权。

“本会话可前台控制的窗口”列出当前授权，点击“停止并撤销窗口控制”会暂停本会话的电脑操作。暂停、关闭桌面能力、切换投递模式、驱动重置或会话结束都会清除前台控制授权；再次识别发现目标已消失时也清除其授权。启动正常应用的一次确认同时涵盖它返回的新窗口，运行需额外确认的程序不自动取得持续窗口控制。敏感动作仍单独确认。应用的“始终允许”不等于跨会话永久取得前台鼠标和键盘控制。后台动作仍不会自动变成前台动作。

底层控制会话结束后，点击面板“恢复”会为本会话建立新的连接和输入会话，先重新观察，再按需授权前台控制。旧观察和原先排队的动作失效，不会自动重放；其他会话的连接保持独立。

## 连续输入

`computer_bounded_input` 提供通用的持续按键、鼠标按住和相对移动，可组合执行。单次 10 毫秒至 10 秒，默认建议先用短动作校准；窗口必须已获授权并处于前台，鼠标动作还要求指针位于目标窗口内。已有用户按键或鼠标按住时不会接管。相对位移的实际屏幕距离、3D 转角取决于系统和应用设置。

动作完成、失焦、Esc、取消或控制端失联时释放输入；独立监护进程处理执行进程异常，未确认清理结束前不开始下一步。不会跨工具调用无限保持按键。每段动作后重新观察，长按挖掘等连续动作需要选择足够时长，不能假设分段松开仍保留应用中的进度。

Minecraft 26.3 用作综合验收场景，输入能力也适用于其他应用与 3D 视图。菜单可操作不等于已能持续游玩；后台截图也不等于后台游戏输入。详细验收边界见 [游戏控制设计](design/GAME-CONTROL.md)。

需要把几个短动作连贯执行时，可以在新会话选择原生 **PTC 模式**。模型使用 DSH 生成的 SDK 逐个 `await` 调用现有电脑工具，权限、取消与日志仍走原生流程；参数数量、时长和位移限制不会因切换模式而放宽。截图在该段执行结束后交给模型，因此只应串联无需中间判断的动作，失败后停止后续输入。PTC 减少动作之间的模型等待，不等于实时视觉控制，也不保证模型能完成任意游戏任务。

## 模型与效果

窗口截图会标明实际像素尺寸。`computer_zoom` 将局部图像放大至最多 4 倍；点击放大图时必须使用 `computer_click` 的 `from_zoom:true`，新观察或动作后旧放大图失效。`computer_move_pointer` 移动真实鼠标并悬停，不点击，可读取应用的提示文字；它要求目标已在前台，使用完整窗口截图坐标。图标不明确时优先核对文字，不凭纹理猜测。

窗口截图可能不包含输入法候选栏等独立浮层。观察结果提供目标窗口线程的只读输入法兼容诊断；部分输入法不支持查询，未知不会当作已关闭。游戏或快捷键中的字母被输入法接走时，应取消组词、通过应用支持的快捷键切换输入模式，再验证实际效果；任务结束核对并恢复原模式。PX 不自动修改系统输入法设置。指针被其他窗口拦截时会报告实际命中的窗口编号和位置，保持拒绝输入；即使该窗口被系统标为隐藏，也不能据此绕过目标检查。

- 支持图片的模型（如 DeepSeek V4-Flash）会收到窗口截图，可以按像素坐标操作没有界面元素的区域。
- 只支持文本的模型（如 DeepSeek V4-Pro）只收到界面元素树和网页结构，截图类工具不可用；遇到只能按像素操作的界面时，Agent 会请你切换模型。
- 刚启动的应用可能需要片刻才能读取到界面元素；后台输入不可用时，可以检查控件是否支持语义赋值。需要前台则按上述流程请求，不能把驱动的重试建议视作用户授权。

## 安装与数据

功能包依赖 [Cua Driver](https://github.com/trycua/cua) 0.28.0 的 SDK 和 [Playwright MCP](https://github.com/microsoft/playwright-mcp) 0.0.80，安装时由 DSH 插件管理器从 npm 下载。匹配版本的 Cua 原生 EXE 与 PX Windows 执行器随功能包交付，启动时校验摘要，不在用户机器上临时编译。浏览器使用本机已安装的 Microsoft Edge，不另外下载浏览器。

设置保存在 DSH_HOME 的 `storages/dsh-px-computer/settings.json`，PX 专用浏览器配置保存在同目录的 `edge-profile`。浏览器运行时的快照与截图文件写入系统临时目录，会话结束后删除，不会写入你的项目目录。设计依据见 [电脑操作设计](design/COMPUTER-USE.md)。
