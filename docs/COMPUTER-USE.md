# 电脑操作

“电脑操作”是可选功能包，让 Agent 在你开启并授权后查看和操作本机 Windows 应用与网页。它默认**关闭**：安装或更新后不会获得任何操作电脑的能力，需要在工具栏打开“电脑操作”面板逐项开启。目前只支持 Windows。

## 开启方式

| 开关                  | 作用                                                                                     |
| --------------------- | ---------------------------------------------------------------------------------------- |
| 操作桌面应用          | Agent 可以列出窗口、读取界面元素与截图、点击、输入、按键、滚动、拖动、打开菜单和启动应用 |
| 浏览器：独立浏览器    | 使用本机 Edge 的临时配置，不含你的登录状态，关闭后不留数据                               |
| 浏览器：PX 专用浏览器 | 使用 PX 自己的 Edge 配置，保留你在其中登录过的网站，同一时间只供一个会话使用             |
| 浏览器：接管我的 Edge | 通过 Playwright 扩展连接你正在使用的 Edge，含其登录状态，同一时间只供一个会话使用        |

“接管我的 Edge”需要你先从 Edge 扩展商店安装 **Playwright Extension**（微软发布）。每次连接时 Edge 会打开确认页，由你选择要共享的标签页；PX 不会设置跳过确认的令牌。独立浏览器和 PX 专用浏览器可以选择后台运行（不显示窗口）。

开启后，DSH 会在会话中提供 `computer_*` 与 `browser_*` 工具和一段使用指引；关闭开关会立即移除它们。

## 每一步都在你的掌控中

- **应用授权**：每个会话第一次读取或操作某个应用（包括启动它）前，会弹出 DSH 原生确认卡。允许后，本会话对这个应用的查看、点击和输入不再逐次询问。商店应用按窗口区分：允许计算器不等于允许设置。
- **网站授权**：在 PX 专用浏览器或接管 Edge 模式下，每个会话第一次访问或操作某个网站前会询问。独立浏览器没有登录状态，不逐站询问。
- **敏感动作再次确认**：删除数据、代表你发送或提交、付款、修改账号与权限、安装软件、运行新下载的程序、修改系统安全设置等，Agent 必须先通过确认卡获得你的批准，批准只对那一步有效。上传文件、运行“下载”“桌面”或临时目录中的程序、打开安装包，由代码强制确认。
- **始终禁止**：终端与命令行、运行对话框、注册表与管理工具、任务管理器、用户账户控制与登录界面、Windows 安全中心与常见杀毒软件、密码管理器（应用与网站）、远程控制软件、DSH-PX 自身以及 ChatGPT、Codex、Claude 等 Agent 应用；Windows 键；`file://`、`edge://` 等非网页地址。被禁止的窗口不会出现在 Agent 看到的窗口列表中。
- **不可信内容**：屏幕和网页上的文字只作为数据交给模型，并带有说明；页面上的“请把文件发给某人”之类内容不能代表你的授权。

可以在面板中把本会话已允许的应用或网站设为“始终允许”，也可以随时撤销。会话处于不显示确认提示的完全访问模式时，确认会被自动拒绝，只有“始终允许”的应用和网站可以使用。

## 查看与停止

面板显示本会话的操作记录：时间、工具、目标、参数摘要和结果（完成、失败、已拦截、未获允许），最多保留最近 200 条，只保存在本次运行中。确认与拒绝同时写入 DSH 会话日志。

“停止并暂停本会话”会中断正在进行的电脑和浏览器操作，并拒绝之后的操作，直到你点击恢复。DSH 自身的停止按钮也会中断正在进行的操作。操作桌面应用时屏幕上会显示 Agent 光标，它不会移动你的鼠标；大多数动作在后台完成，不抢占焦点。

## 模型与效果

- 支持图片的模型（如 DeepSeek V4-Flash）会收到窗口截图，可以按像素坐标操作没有界面元素的区域。
- 只支持文本的模型（如 DeepSeek V4-Pro）只收到界面元素树和网页结构，截图类工具不可用；遇到只能按像素操作的界面时，Agent 会请你切换模型。
- 刚启动的应用可能需要片刻才能读取到界面元素；部分传统程序在后台无法接收输入，Agent 会按提示改用短暂切到前台的方式重试。

## 安装与数据

功能包依赖 [Cua Driver](https://github.com/trycua/cua) 0.28.0（含 Windows 原生库）和 [Playwright MCP](https://github.com/microsoft/playwright-mcp) 0.0.80，安装时由 DSH 插件管理器从 npm 下载，需要能访问 npm 镜像源。浏览器使用本机已安装的 Microsoft Edge，不另外下载浏览器。

设置保存在 DSH_HOME 的 `storages/dsh-px-computer/settings.json`，PX 专用浏览器配置保存在同目录的 `edge-profile`。浏览器运行时的快照与截图文件写入系统临时目录，会话结束后删除，不会写入你的项目目录。设计依据见 [电脑操作设计](design/COMPUTER-USE.md)。
