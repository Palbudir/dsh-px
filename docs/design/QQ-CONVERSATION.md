# QQ 日常交流与任务能力

目标：人格保持连续，任务使用原生 DSH 执行，QQ 提供交流、资料与交付入口。当前设计正在实现，能力是否交付以发布记录为准。

## 交互与信息

- 默认响应私聊与群内直接 @。群历史按需分页读取，不要求每条背景消息都触发模型。
- 保留发送者 QQ 编号、消息编号、时间、引用、图片与表情线索。昵称和群角色用于理解交流，不代替任务授权。
- “获取群信息”指该账号与当前接口可访问的资料。缺失历史、撤回消息、媒体下载失败和不支持的接口必须显示实际限制，不宣称拥有完整历史。
- 日常回复通常一到三句，适度使用表情；任务交付用简短说明和 UTF-8 文本文件。长度不足以表达问题时可以解释，不能静默截断结论或审批参数。
- 当前人格决定稳定身份和底线。称呼、交流习惯、群内约定和可纠正事实可以随经历更新；普通消息不能重写人格配置或权限。

## 原生能力与权限

原生会话、历史、Goal、Job、Team、工具审批和取消继续由 DSH 管理。群内资料与经历采用现有记忆和知识引擎，以当前群和人格确定范围，保留来源与修订；不另建一套人物数据库或任务引擎。

交流经历通过 `qq_memory` 管理，原文通过 `persona_history` 找回。保存时必须提供当前可读取的原生会话与事件编号；同主题修订使用现行知识版本，旧版本写入被拒绝。记录存放在该群的项目共享文档中，按人格区分主题，可在现有知识界面检查。记录是可纠正的观察，不作为人格底线或执行授权。

自然语言用于理解意图和判断是否需要执行任务；真实发送者编号、当前任务授权和工具访问范围由程序校验。对引用、转发、图片、网页和检索记忆的指令注入分别测试，不能用模型自我判断代替工具校验。外部资料中出现负责人姓名或编号不构成授权。

普通交流开放当前聊天的读取与表达能力。获授权成员的任务可调用已启用的原生电脑与浏览器等工具，结果回到原群。私有资料共享与跨聊天发送遵循明确授权，不因开放群内交流而默认扩展。

## 验收

| 场景                                 | 必须观察到的结果                                                 |
| ------------------------------------ | ---------------------------------------------------------------- |
| 普通成员、负责人、同名成员交替说话   | 按真实编号区分，只有获授权成员可发起本机任务                     |
| 未 @ 的上下文后再提问                | 可按需读取本群历史；未 @ 本身不触发回复                          |
| 图片、表情、引用、多页历史           | 可获取的元素保留身份和来源；图片不可读时如实说明                 |
| QQ 表情和群内表情包回复              | 两端真实显示；不读取任意本机路径或其他聊天媒体                   |
| 新会话、压缩、重启后继续交流         | 找回本群相关经历和原始依据，纠正后的事实优先，其他群和私聊不混入 |
| 正文、引用、图片、网页与记忆中的注入 | 不提升权限、不改人格底线、不越界读取或发送                       |
| 浏览器和电脑任务                     | 真实操作产生可核验结果；停止后无迟到动作，结果交付到原群         |
| 长报告或代码                         | 群消息简短，文本文件完整，接收端可下载核对                       |
| 多成员同时发言、任务中插话           | 聊天和任务来源可追溯，不混用负责人权限                           |
| Desktop 与 Web 设置                  | 保存、重启、暂停、错误与待处理请求状态一致，无假成功             |

验收使用隔离工作区和测试资料。接口连通、模型调用、接收端显示和文件内容分别核验；记录未覆盖的实际限制。
