# DSH-PX 当前路线图

目标是在本台 Windows 电脑上，基于 DSH 原生插件范式交付成熟 Agent 工作能力。当前基线为 **re.0.7 / DSH 0.1.5-rc.2**。插件是工程实现方式；验收对象是完整任务及其结果。

详细规划已收敛到 [2026-09-22 能力审计与路线图](agent-maturity-2026-09-22/README.md)：

| 阶段 | 功能数 | 重点 |
|---|---:|---|
| 短期 | 30 | 本机执行、网页抓取、任务状态、证据准确、只读边界、独立验收 |
| 中短期 | 30 | 项目上下文、工作树/PR/恢复、浏览器、研究与 Office 产物 |
| 长期 | 24 | 大项目、多小时/跨日任务、稳定集成、长期故障测试 |
| 远目标 | 16 | 按实际收益选择复杂自主工作、电脑操作与可复用流程 |

- [交互筛选与详情](agent-maturity-2026-09-22/index.html)
- [100 项完整目录](agent-maturity-2026-09-22/feature-catalog.md)
- [18 项问题和修复排期](agent-maturity-2026-09-22/findings.md)
- [真实安装版评测和复现](agent-maturity-2026-09-22/evaluations.md)

阶段是优先与依赖顺序，不是所有条目同时开工的日期承诺。首批发布拆分、验收门槛和单项人日见主报告。现有 Git、计划、终端、子任务等基础应优先复用；新增能力仍走 DSH 原生工具、服务、Skills、组合包和侧栏扩展。

开发流程继续为：**功能分支 → 自动检查与真实任务 → PR → tag/Release → 原安装版更新 → 配置、会话与能力复核**。纯文档审计通过文档 PR 交付，不发布空应用版本。当前不投资跨平台分发、云端部署、多人治理或插件商业市场。

早期“只包装官方、能力持平为上限”的路线图已退役，历史原文保留于 [包装阶段归档](history/ROADMAP-packaging-baseline.md)。当前产品目标见 [PRODUCT.md](PRODUCT.md)。
