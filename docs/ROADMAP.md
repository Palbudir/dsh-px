# DSH-PX 当前路线图

目标是在本台 Windows 电脑上，基于 DSH 原生插件范式交付成熟 Agent 工作能力。当前开发版本为 **re.0.10 / DSH 0.1.5-rc.2**，审计快照仍以 re.0.7 为基线。插件是工程实现方式。

re.0.10 暂缓扩展能力，优先做实际使用、日志分析、前端一致性和仓库规范。[本轮 23 项审查](quality-2026-09-24/README.md) 分开记录确定缺陷、体验建议、历史现象与环境限制；后续优先追踪原生文件版本保护、社区任务面板自动切换以及 Windows 子进程边界。

re.0.9 按用户最新优先级建设会话标签、文件/终端直达、会话产物、引用批注和定时任务管理；复用 DSH 的后台任务与子 Agent 完成唤醒。对应 M12/M22/M24/M27 和 L11/L24 的第一阶段，范围与边界见 [会话工作区版本说明](releases/re.0.9.md)。长时间运行可靠性、完整跨会话知识管理仍是后续工作。

2026-09-23 起，每版以声明的功能实现及可复现验收作为硬门槛，实用性和 Agent 整体效果作为软观察。re.0.8 覆盖 S03/S04/S05、S17/S18、S24 的读取错误分层，以及 S29 在本机静态 HTTP 代理场景的接入与诊断；具体范围和限制见 [版本说明](releases/re.0.8.md)。S01 的 Windows 子进程限制、S02 的 todo 终态和 S06 的只读审查仍待后续版本。

详细规划已收敛到 [2026-09-22 能力审计与路线图](agent-maturity-2026-09-22/README.md)：

| 阶段 | 功能数 | 重点 |
|---|---:|---|
| 短期 | 30 | 本机执行、网页抓取、任务状态、证据准确、只读边界、独立验收 |
| 中短期 | 30 | 项目上下文、工作树/PR/恢复、浏览器、研究与 Office 产物 |
| 长期 | 24 | 大项目、多小时/跨日任务、稳定集成、长期故障测试 |
| 远目标 | 16 | 按实际收益选择复杂自主工作、电脑操作与可复用流程 |

阶段是优先与依赖顺序，不是所有条目同时开工的日期承诺。首批发布拆分、验收门槛和单项人日见主报告。现有 Git、计划、终端、子任务等基础应优先复用；新增能力仍走 DSH 原生工具、服务、Skills、组合包和侧栏扩展。

开发流程继续为：**功能分支 → 自动检查与真实任务 → PR → tag/Release → 原安装版更新 → 配置、会话与能力复核**。纯文档审计通过文档 PR 交付，不发布空应用版本。当前不投资跨平台分发、云端部署、多人治理或插件商业市场。

早期“只包装官方、能力持平为上限”的路线图已退役，历史原文保留于 [包装阶段归档](history/ROADMAP-packaging-baseline.md)。当前产品目标见 [PRODUCT.md](PRODUCT.md)。
