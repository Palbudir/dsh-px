# 小版本验收与本机构建材料

只复测本次改动和相关失败路径；已有同提交的有效证据不重复执行。以下清单补充 [发布流程](RELEASING.md)，不是新的审查门禁。

## 电脑操作界面回归

用独立 DSH_HOME 和测试会话，通过正常页面操作原生授权卡，不模拟批准返回。Electron 与 Web 分别检查；模型使用可用的 DeepSeek Flash。专用浏览器仅使用测试 profile，不接管日常登录态。

| 场景         | 操作与通过条件                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------ |
| 默认状态     | 新配置的桌面和浏览器能力均关闭；开启后才提供对应工具                                             |
| 关闭浏览器   | 请求未授权网站，卡片出现后关闭浏览器模式；卡片消失、工具结束，不创建新浏览器、不返回网页内容     |
| 关闭桌面     | 请求启动测试应用，卡片出现后关闭桌面能力；卡片消失，应用不启动                                   |
| 暂停与恢复   | 等待授权时暂停，卡片自动取消、当前调用结束；恢复后重新请求，不复活旧调用                         |
| 正常桌面任务 | 批准计算器访问，用界面完成运算，读取实际结果；支持图片的模型须收到图片内容                       |
| 正常网页任务 | 在本地无外发的测试页读取校验码、填入文本框并预览，重新读取回显；仅导航返回标题不等于正文读取通过 |
| 停止与清理   | 停用后只结束测试实例拥有的驱动与浏览器；不结束共享应用宿主或用户窗口                             |

记录确切 SHA、运行产品/插件版本、实际结果与未测项目；模型最终总结不能代替工具结果。保留失败原件，每次运行使用新目录，不能覆盖上一次失败截图或日志。多显示器、坐标与拖拽、扩展接管分别记录，未做不计通过。

Electron 隔离运行须设置 `DSH_PX_USER_DATA_DIR` 和 `DSH_PX_DISABLE_PROTOCOL_REGISTRATION=1`。若使用浏览器自动化，已有 Playwright 和临时浏览器配置即可完成本地页面回归，不要求安装新的浏览器扩展。

## 构建材料保留与清理

`build-test/` 是被 Git 忽略的本机工作区，不是交付物。体积增长不应通过删除历史发布资产处理。

- 保留当前发布的正式资产、清单、审查结论和真实验收证据，以及必要的上一版回退材料。
- 保留未解决问题的原始失败证据、正在运行的实例、仍被 junction 引用的依赖、锁定的上游检出。
- 可清理已结束运行的重复解包、废弃候选、下载分块、临时编译测试产物；先列清单，确认绝对路径位于该工作区并检查引用，不跟随 junction 删除目标。
- 凭据、会话、用户配置、迁移备份与业务存储不属于普通缓存；不要把含这些内容的目录当作可重建构建删除。
- 保留清理前后目录清单与体积变化；清理本机材料不改变产品版本，也不重发同版本安装包。

通用校验脚本维护在 `scripts/`；原始会话、截图、模型审查正文及带机器路径的运行报告留在忽略目录。新验证应参数化版本与来源，避免复制旧发布脚本里的固定 SHA、版本号和功能包数量。
