# re.0.10 · 交互与维护

[对应发布](https://github.com/Palbudir/dsh-px/releases/tag/v0.1.0-beta.re.0.10)

- 修复固定标签关闭后的会话选择、重复创建终端、切换面板丢失表单草稿及开发环境更新反馈。
- 统一自制页面的主题、图标、控件、焦点、错误和禁用状态；减少动态效果时关闭自有过渡动画。
- 为删除操作增加确认，保留刷新期间的已有内容，减少隐藏页面和卸载后的无效请求。
- 批注分页读取，降低调度轮询和长会话面板的开销。
- 加强本机接口来源检查、压缩版本响应处理及插件产物一致性检查。
- 整理插件目录与构建工具；开发入口默认隔离数据，Electron 更新至 44.4.5。

应用内安装第三方插件仍受其运行依赖约束。文件版本保护继续生效。HTML 预览若被浏览器检查器或策略拦截，应先区分环境限制与产品错误。

手动检查更新造成的服务心跳问题随后由 [re.0.10.1](re.0.10.1.md) 修复。
