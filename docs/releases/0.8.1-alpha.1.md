# Pack / Desktop 0.8.1-alpha.1

本版增加普通 QQ 账号接入。下载安装状态以 GitHub Releases 为准；先更新 Desktop，再更新 Pack，兼容代际仍为 0.8。

- 在“设置 → QQ 账号”连接本机 NapCat / OneBot，选择固定人格、独立工作区、授权成员和 QQ 默认模型。QQ 与桥接需另行安装，手机登录由用户完成。完整步骤见 [QQ 使用说明](../QQ.md)。
- 私聊与群内直接 @ 可以交流。只有授权成员可以发起本机任务；授权按真实账号编号判断，昵称和聊天中的身份声明不会授予权限。
- 群交流可以读取本群历史和成员信息、查看消息中的图片、发送 QQ 表情，以及复用本群已见的图片和动图。长消息可分页续读；媒体引用绑定当前会话和聊天，不能指定任意本机路径或其他收件人。
- 人格可以记录并找回本群的交流经历、称呼和偏好，保留原始消息依据；同名成员按 QQ 编号区分，纠正信息通过原生文档修订保存。这些记录不授予任务权限，也不会自动混入人格私有资料。
- 长说明与生成内容可以作为 UTF-8 文本文件交付，群里只保留简短说明。普通成员也可以请求生成文本文件，但不能因此读取本机文件。
- 群任务留在原群交付，使用独立的群工作目录与原生任务会话。普通群交流和任务输入分别管理；私有记忆与其他私聊不自动加入，私有材料需要明确分享。`/task` 继续任务，`/newtask` 创建新的任务会话，`/stop` 请求停止。
- 原生问题、计划确认与工具审批可以在 QQ 回答，也可以在客户端处理同一个请求；普通“好的”不会当成工具审批。取消后的旧请求无法再次批准。
- QQ 命令切换模型只影响当前会话，QQ 默认模型设置也不改变 DSH 全局默认。同档切换和跨档接续沿用原生模型目录与 PX 档位规则。
- 保留原生会话与日志，识别重复消息和受理不明确的请求；存储损坏时保留原件并停止新的投递，不自动重跑副作用。
- 修复原生模型选择器在部分浏览器入口缺少会话依赖的问题，以及 QQ 设置在较窄窗口被长目录名挤出的布局问题。
- 修复接续群任务显示为“未命名”的问题，保留用户手动修改的标题；电脑操作确认过期时给出可重新发起的提示，不再误判为确认界面未显示。

QQ 功能默认关闭。社区通道由固定来源 `dsh-onebot-qq 0.9.6` 派生，保留上游名称和许可；用户已有的同名安装与配置不会被静默替换。当前任务工具只向原聊天交付，不开放任意跨聊天发送；群任务不提供跨渠道 IM、跨会话原始查询和定时任务工具。已覆盖文字、图片、GIF、QQ 表情、文本文件和审批；语音、视频、通话及其他 QQ 业务功能不在本版验收范围内。历史可读范围仍受 QQ 已同步记录和桥接能力限制。
