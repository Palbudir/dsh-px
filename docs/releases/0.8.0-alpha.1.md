# Pack / Desktop 0.8.0-alpha.1

本版升级官方宿主与社区插件，并增加经验整理和 IM 任务入口。下载安装状态以 GitHub Releases 为准；从 0.7 升级时先更新 Desktop，再使用同代际 Pack 的独立更新。

- 宿主升级至 DSH 0.2.1-rc.3，适配 dsh-context 0.75.1、dsh-mnemon 0.5.34 和独立社区成员 dsh-im 5.6.0。保留社区原包的配置与启停入口。
- 原生 Job/Team 工作等待可被任务变化或用户插话唤醒。工具返回期间可以继续处理独立工作；模型仍需根据任务依赖决定并行和交付顺序。
- 在“记忆与知识 → 知识与 Skills → Skills”整理已完成的工作经历，查看依据、生成和编辑候选、比较基线与候选方案，再由用户采纳至项目技能目录。方案模拟不等于真实工具执行验证；候选按人格和项目隔离，采纳后成为项目共享 Skill。
- 飞书等 IM 渠道通过原生机器人配置接入，共用 DSH 会话、任务和权限；渠道接入不会自动开启电脑操作。机器人账号和凭据需自行配置。
- 保留原生模型选择器和标签扩展，同档切换与跨档新会话接续适配新宿主；未填写容量仍使用最低档策略。
- 修复嵌套项目的相对文件定位、Markdown 图片和本地文件跳转，以及保存期间继续输入时的草稿处理。HTML 预览沿用沙箱，动态本地请求和模块脚本仍需开发服务器。

BrowserSkill 适配、预测式异步推理和外部语义记忆服务不在本版交付范围。长任务和并行能力仍依赖模型实际行为，不承诺任意任务自动提速。
