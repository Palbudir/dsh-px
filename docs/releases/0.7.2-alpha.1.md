# Pack 0.7.2-alpha.1

本版继续兼容 Desktop 0.7.0-alpha.1，按原生更新流程独立更新 Pack。下载安装状态以 Releases 为准。

- 后台桌面操作不再绘制覆盖用户屏幕的代理光标；用户切换无关应用不再被误报为被控应用抢前台。固定版本的 UIA 赋值补充投递方式回执。
- 新配置中的独立浏览器默认后台运行，面板说明临时实例与共享登录模式的区别；已有设置保留。
- 增加可选应用内输入桥和独立实例工具，复用原生会话权限、停止和操作记录。当前适配 Minecraft Java 26.3 的独立 Fabric 实例，提供真实画面、虚拟鼠标、持续按键与取消释放；不改变日常游戏实例，不提供游玩策略。
- 输入桥使用一次性画面标识、实例身份和短期控制租约。失联、暂停或界面变化时停止持续输入；释放未确认时不继续操作，不回退到系统鼠标。

使用方法、安装步骤与边界见 [后台操作与独立实例](../INDEPENDENT-INPUT.md)。普通窗口的后台覆盖取决于控件和应用，不能将本版理解为任意软件都能完全后台运行。系统锁定、停止渲染、应用线程卡死与独立虚拟机不属于本版的持续可用承诺。
