# re.0.8 · 执行证据与网页诊断

[对应发布](https://github.com/Palbudir/dsh-px/releases/tag/v0.1.0-beta.re.0.8)

- 执行摘要与 `task_review` 支持历史分页，`task_evidence` 可按调用编号分段读取输出。
- 工作摘要可引用本会话更早的已结算执行；拒绝伪造或跨会话证据。
- 区分正常返回、取消、中断与命令异常；读取历史错误文字不再误判为当前执行失败。
- 查看文件不计作写入，已知只读操作不再单独触发摘要过时提醒。
- 会话不存在、损坏、不兼容、权限不足及暂时忙具有明确读取错误。
- 无显式代理配置时可接入 Windows 已设置的本机静态 HTTP(S) 代理；运行与帮助提供实际网页读取检查。

输出只限会话已经保存的内容，上游未保存的文本无法恢复。文件写入路径不等于完整 Git 差异。自动代理接入不处理 PAC、SOCKS、带认证或远程系统代理，也不改写系统设置或用户显式配置。
