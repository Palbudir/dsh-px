# Desktop 0.7.1 / Pack 0.7.3：大体积 Pack 更新

Desktop 0.7.1-alpha.1 修复旧更新器将 Pack 下载限制为 32 MiB 的问题。包含 Windows 原生驱动的 Pack 已超过该限制；旧客户端可能把正常下载误报为“下载内容超出签名清单大小”。

- Pack 下载上限提高到 512 MiB，单层归档解压上限提高到 1 GiB；超过客户端支持范围时给出明确提示。
- 下载直接写入一个有界缓冲区，避免保留所有分块后再复制一份完整归档；下载总超时延长至 15 分钟。
- 仍严格校验签名声明的实际大小、摘要、来源与插件组合，超过签名大小的响应立即取消，截断文件不能安装。
- 客户端配套 Pack 0.7.3-alpha.1，保留 0.7.2 的后台操作、独立浏览器与可选 Minecraft 输入桥；协议代际仍为 7，DSH 核心版本不变。

请先通过 **应用 → 检查更新 → 桌面客户端**更新 Desktop。客户端随附匹配的 Pack，启动后检查实际激活版本；之后同代际 Pack 可独立更新。原有发布标签和资产保持不变。

上限是客户端接收能力，不表示推荐把 Pack 做到该大小；下载和解包仍占用内存。独立游戏输入桥仍需在独立 Fabric 实例中安装，不会自动修改现有游戏。
