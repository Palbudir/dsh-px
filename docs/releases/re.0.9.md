# re.0.9 · 会话工作区

> 后续定位修正：本页 HTML 预览项在 re.0.10 审查中确认受到浏览器检查器拦截，现归为“验收受限”，暂不判定为产品 P1 缺陷，见 [Q18](../quality-2026-09-24/README.md)。下文保留当时记录。

本版把常用操作接到 DSH 原生会话、输入框、侧栏和任务运行机制。只验收本台 Windows 电脑。

## 范围和硬验收

- 会话标签：打开、切换、关闭、固定、恢复最近关闭；刷新恢复标签。关闭标签仅关闭视图，运行中的任务和会话历史保留。切换会话保留草稿。
- 主界面入口：文件、终端、产物、后台任务、引用批注、定时任务。文件与终端复用原生/社区侧栏，支持实际文件预览及命令执行。
- 产物：按会话汇总 `present` 已声明交付，打开原文件；明确记录不是文件快照。
- 引用批注：读取已保存的用户/助手正文，选择原文片段、保存批注、编辑/删除、插入当前会话草稿。引用有来源，不自动发送，不覆盖已有草稿。
- 定时任务：一次/间隔/每日、指定会话、编辑、启停、删除、立即投递、查看投递记录。重启保留；到期通过原生 Session Controller 队列唤醒目标 Agent，沿用会话模型和权限。
- 调度可靠性：重复任务跳过离线积压；投递前持久登记；不确定投递暂停并提示核对，避免无声重复；已投递不等于 Agent 已完成。应用退出期间不执行。
- 后台/子 Agent：复用原生所有者路由与完成唤醒；验证空闲父 Agent 能收到完成通知并继续，切换 UI 不改变通知归属。
- 交付：类型检查、行为测试、打包与启动验证、隔离环境 UI 验收，PR 合并、Release、本机原安装更新及数据保留检查。

实用性和 Agent 效果作为观察记录，不取代以上功能验收。

## 使用方式与边界

顶部标签可以固定、关闭和恢复；`Ctrl+Alt+左右方向键` 切换，`Ctrl+Alt+T` 恢复最近关闭。文件、终端、变更与后台任务使用现有侧栏组件。产物只汇总明确 `present` 的文件，不把所有写入误当交付。

助手消息的“引用 / 批注”直接定位正文；用户消息可以从“引用与批注”的正文列表选择。选中原文片段后填写批注，可保存、编辑及加入草稿。不会自动发送。批注默认不进入 Agent 上下文。

定时任务支持一次、至少 1 分钟的固定间隔及本机每日时间。最多保存 100 个、同时启用 20 个；每个任务保留最近 20 次投递记录。应用退出时不执行，也不会启动系统级常驻服务。休眠或停机后的重复任务只补一次，不连续追赶积压。任务仍可能遇到会话原有的模型错误或权限审批；“已投递”不代表完成。

插件业务数据保存在 `DSH_HOME/storages/dsh-px-workspace/workspace.json`，会话正文仍以原生持久化为准。损坏文件不会被空数据覆盖；投递未确认、投递期间退出和时区变化会暂停并提示核对目标会话。关闭界面标签不取消 Agent 或已投递任务。

## 本轮发现的边界

- 现有 HTML 预览在本机 Edge 中显示浏览器拦截，未启用侧栏的“临时解锁”。此项不计为 HTML 预览验收通过，后续作为 P1 产物预览兼容性问题处理；本版验证文件入口与 Markdown 预览。
- 原生后台任务面板可能在新任务启动时自动切换到前台。未更改用户现有侧栏偏好，后续应提供“仅显示提醒、不抢占面板”的产品级默认行为（P2）。
