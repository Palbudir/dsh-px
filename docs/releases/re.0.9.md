# re.0.9 · 会话工作区

[对应发布](https://github.com/Palbudir/dsh-px/releases/tag/v0.1.0-beta.re.0.9)

- 新增会话标签的打开、切换、固定、关闭、最近关闭恢复与刷新恢复。
- 增加文件、终端、代码变更、产物、后台任务、批注和定时任务的集中入口。
- 按会话汇总明确声明的交付文件；查看文件当前内容，不创建产物副本。
- 支持从用户或助手正文选择连续原文，保存批注并按需追加到输入框。
- 支持一次、固定间隔和每日定时要求，向指定会话的原生队列投递；沿用会话模型与权限。
- 复用 DSH 的后台命令和子 Agent 完成通知。

关闭标签不会取消任务。批注不会自动发送或自动进入模型上下文。服务停止期间不执行定时任务；已入队不代表任务完成。后续维护版本进一步完善了调度、草稿和服务恢复。

快捷键：`Ctrl+Alt+左右方向键` 切换会话，`Ctrl+Alt+T` 恢复最近关闭的标签。
