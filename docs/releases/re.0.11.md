# re.0.11 · 可靠性与升级恢复

[对应发布](https://github.com/Palbudir/dsh-px/releases/tag/v0.1.0-beta.re.0.11)

本次更新以本机可靠性、升级恢复和日常交互为主。

- 修复定时任务在慢投递、暂停和修改计划时的重复触发及状态关联问题。
- 保留批注与定时表单的未保存内容，明确处理多窗口布局冲突，改进长历史和执行输出的按需读取。
- 改进桌面与浏览器的实例识别、更新回执，以及活动任务等待、停止失败后的恢复流程。
- 改进运行时和受管插件的升级与失败恢复，保留个人配置；业务存储损坏时隔离故障并保留原文件。
- 整理自制面板的诊断文案、依赖提示，以及键盘、主题和缩放行为。
- 修复发布资产名称与更新索引不一致造成的下载问题。

升级前请保存未提交的批注和定时表单，并结束正在运行的任务、关闭终端。原生工具权限、文件版本保护和 Windows 子进程限制继续生效；受限命令仍需按实际提示处理。
