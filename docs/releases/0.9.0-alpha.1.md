# Pack / Desktop 0.9.0-alpha.1

本版兼容代际为 9，需要先升级到 Desktop 0.9.0-alpha.1，再使用同代际 Pack。人格导航、私有技能目录和原生历史授权随客户端一并更新；连接该客户端的 Web 页面获得相同能力。独立官方宿主保留保护性限制。

- 每个人格拥有独立会话、记忆与私有 Skills；共有工具、渠道和公共 Skills 按人格资源规则使用。换人格时打开对应会话或明确接续，已有会话保留原身份。
- 记忆保留来源、修订与反馈。重复引用同一执行回执不会反复加权；纠正或归档来源后，旧共享快照不再作为现行知识返回。分享资料需明确选择范围。
- 长会话通过原生 Job 后台整理较早片段，在安全步骤提交；原文仍可检索。当前工作账本与原生 Goal／Team 状态一起帮助跨压缩和重启接续。
- QQ／飞书提供普通、专注和仅通知接收方式。通知判断分批处理，可在允许范围内临时关注；聊天、任务权限和资料受众分别校验。
- 人格可在明确授权的场合交流指定内容。回信通过原生后台作业返回，不自动共享私人会话或替代任务完成依据。
- Team 可以并行工作并响应中途纠正。独立浏览器可同时工作；共享浏览器与前台键鼠协调占用，旧令牌不能释放新的占用。
- 修复持续按键未计入前台活动调用的问题。取消正在进行的输入后释放按键，恢复时要求重新观察；未知发送结果不自动重放。
- 修复飞书新增账号后遗留创建入口，以及同配置重新启用时未自动恢复接收的问题。

使用入口：左侧“记忆与知识”管理人格、资料和 Skills；设置中的“渠道与活动”管理飞书与人格通信，“QQ 账号”管理普通 QQ 桥接；“当前任务”查看原生工作状态，“电脑操作”查看和释放资源占用。

升级保留现有工作区、会话、凭据和第三方配置。启用新渠道或人格通信仍需用户配置。QQ 免打扰由 PX 管理，不与官方 QQ 自动同步；飞书受管接收端当前以文本能力为准。Windows 后台操作按具体应用和动作支持，持续游戏输入仍遵循前台或已适配输入桥规则。
