# 0.6.0-alpha.1

Pack 与 Desktop 配套升级到兼容代际 0.6，原生 DSH 继续使用 0.2.0-rc.2。先更新 Desktop，再使用同代际 Pack 的独立更新。

- **四范围知识**：人格私有、人格 × 项目、项目共享和全局共享，复用 Mnemon Documents 引擎。支持同主题纠正、归档、显式分享、来源文件版本和历史查看；原文被纠正后，旧共享副本不再作为当前结论返回。
- **原生技能管理**：查看已有 Skills，创建、编辑和启停 PX 管理的技能；展示实际项目/全局目录，遵守当前会话文件权限和版本冲突检查。
- **长任务连续性**：原生 Team 子智能体继承固定人格及知识视图调用说明，保留真正执行者与原生权限；账本、任务状态和历史证据分别核对。可选 Team 服务缺失时不再触发 Cordis 服务访问错误。
- **更新原因更明确**：单纯权限配置通知不会再被误报为工作；运行中的会话、排队输入和后台任务保留阻止更新的具体原因。
- **界面适配**：Mnemon 原生页面可浏览 PX 知识；知识/技能草稿保留，冲突与权限拒绝给出明确说明；修正侧栏 WebSocket 在 Desktop 自定义页面协议下的连接地址。

受管 Mnemon 组合首次升级采用 PX 知识与 General 策略，原项目档案保留手动入口；用户自行安装的社区配置不被改为受管。后续用户设置保留。不默认启用外部记忆 Provider、自动历史提炼或语义向量检索。

文件版本相同不代表知识结论已经得到文件支持。历史结果和工作账本不等于当前任务成功；重启后仍须核对原生任务与回执。支持范围与用法见[人格、经历与工作账本](../MEMORY.md)。
