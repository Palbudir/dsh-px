# Pack 0.7.4-alpha.1：统一记忆与知识工作台

左侧“记忆与知识”统一管理人格约定、经历检索、知识与 Skills。默认打开实际内容；存储路径、Provider、其他记忆来源和兼容诊断保留在高级页。

- 人格约定直接展示并支持编辑、忘记；人格配置收进“人格与协作偏好”。会话开始后仍固定人格，换人格继续使用新建接续会话。
- 历史检索展示简短片段，并在对应结果内展开原文，保留原事件定位和分段读取。
- 知识用“谁可以使用？”表达四种原有范围，并优先显示最近修改的条目；文档修订、共享和归档仍由原生引擎处理。
- 人格和知识草稿在当前窗口切页后保留，保存时继续检查原版本。
- 高级入口保留原 Mnemon 管理与配置。停用 PX 记忆插件后，原生导航自动恢复；不修改社区插件配置或迁移存储。

这是 Pack 界面更新，协议代际仍为 7，Desktop 保持 0.7.1-alpha.1。建议先使用 Desktop 0.7.1 或更新的兼容客户端，再通过原生更新窗口独立更新 Pack。
