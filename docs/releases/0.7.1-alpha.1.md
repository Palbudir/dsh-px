# Pack 0.7.1-alpha.1

修复电脑操作与原生会话权限冲突：已开启电脑操作能力的“完全权限”会话，可以直接进行普通应用、网站和前台窗口操作，不再因关闭确认提示而被首次授权阻塞。

- “应用与网站授权”显示本会话实际识别到的目标，包括尚未允许的应用和网站；可直接选择本会话允许或始终允许。
- 普通完全权限授权每次读取原生状态，不保存成跨会话白名单；切回工作区内修改后重新遵循确认流程。
- 未知权限、Auto 模式或单独关闭询问不视作完全权限。敏感动作、能力开关、仅后台模式、暂停及禁止目标仍遵循各自限制。
- 拒绝提示区分普通访问与需要单独确认的动作，避免让模型反复申请或引导用户寻找尚不存在的入口。

仅更新 Pack，兼容 Desktop 0.7.0-alpha.1；通过“应用 → 检查更新”更新插件整合包即可，无需重新下载客户端。DSH 核心仍为 0.2.0-rc.2。
