# Pack 0.8.2-alpha.1

本版新增可配置的人格表达与 QQ 消息模式。兼容代际仍为 0.8，可在 Desktop 0.8.1-alpha.1 上独立更新 Pack；下载及公开状态以 GitHub Releases 为准。

- 人格提供灵动交流、严谨助手和自然协作三个可编辑起点，支持自定义性格、原则及说话示例。公开表达与私人协作要求分开保存，通过原生提示词与会话版本管理生效。
- QQ 设置统一预览所选人格；专注聊天、普通、仅通知分别控制完整消息、预览和提醒。模式切换不重连，也不中断已开始的任务。
- Agent 可在允许范围内临时打开聊天、调整模式和群提醒。通知判断使用原生后台作业；只选择关注对象，具体回复及执行仍在原聊天处理。
- 群消息可以被旁听而不回复，也可以只发表情或文件；避免自动补发无意义的确认。长交付继续使用文本文件。
- 专注或关注群中的授权任务可按真实原消息转交，无需每次 @。真实发送者、当前回合和资料受众分别校验；昵称、转述和历史授权不能冒用。
- 收件队列保留状态与原始来源，按模型容量分批处理；不同聊天可以独立推进。停止会取消旧的排队输入，未知投递不盲目重跑。
- 改善模式选择、临时状态、聊天名称与分页、未保存设置保留和窄窗口展示。

使用步骤见 [QQ 账号](../QQ.md) 和 [人格与记忆](../MEMORY.md)。首次采用新表达时，需保存人格模板并让目标会话采用相应版本；升级不会自动改写既有人格内容。免打扰暂由 PX 管理，未宣称与 QQ 客户端设置自动同步。消息可读范围仍受 QQ 已同步记录、桥接能力与本地队列容量限制；语音、视频和通话不属于本次新增能力。
