# 当前能力与运行边界

本页描述当前维护代码的功能契约。应用版本以根 [package.json](../package.json) 为准；可下载安装的版本及已发布变更以 [Releases](https://github.com/Palbudir/dsh-px/releases) 为准。未发布事项见 [路线图](ROADMAP.md)。

## 能力分工

| 能力                                       | 所有者                      | 边界                                                       |
| ------------------------------------------ | --------------------------- | ---------------------------------------------------------- |
| 模型、对话、工具、权限、计划与历史         | DSH                         | 不在 Electron 中重写执行与授权                             |
| 文件、编辑器、终端、代码变更及后台任务视图 | DSH 与 dsh-better-sidebar   | 原生与社区服务须实际激活；禁用侧栏会影响依赖面板           |
| 会话标签、批注、产物与定时任务             | dsh-px-workspace            | 关闭标签只关闭视图；产物展示文件当前内容；定时依赖服务运行 |
| 执行记录与按需证据                         | dsh-px-taskflow             | 工具返回不等于业务成功；工作摘要为可选模型记录             |
| 运行诊断、工作区入口与服务协调             | dsh-px-workbench            | 使用原生服务；未知任务状态不能视为空闲                     |
| 版本、下载与安装                           | dsh-px-updater 与桌面更新器 | 查询、接收、等待、下载和安装分别报告                       |

## 桌面与 Web

- **桌面窗口**拥有本机服务与应用更新器，负责重启、关闭及恢复。
- **浏览器页面**可连接同一个桌面服务，共享会话、模型、插件和已保存业务数据。重启或退出服务会影响全部连接页面。
- **独立 DSH 服务**不一定具备桌面操作能力，不能仅凭相似界面判断为 DSH-PX 实例。
- **开发实例**默认使用隔离数据目录，不提供正式应用安装更新。

“运行与帮助”分别显示页面载体、服务模式和实际激活的依赖。通过托盘打开浏览器可获得正确鉴权入口。端口可能因占用改变，不能把固定端口当作应用身份。

## 状态与数据

会话正文由 DSH 持久化。批注与定时配置保存在插件业务存储中；损坏时保留原文件，并可从有效快照恢复。恢复后的定时任务暂停，核对后再启用。

标签布局按服务数据目录保存，端口变化后仍可找回。多个窗口的布局保存冲突需明确选择，不自动覆盖对方布局。未保存的批注和定时表单属于当前窗口，切换面板保留，关闭前应保存。

定时记录区分投递中、已入队、执行中、轮次结束、失败、取消和中断。轮次结束只表示原生执行结算，是否达到任务要求仍需检查输出。服务离线期间不执行，周期任务不连续补发积压。

正常重启、退出及安装先处理活动 Agent、后台任务、排队输入与打开的终端。终端计数代表尚未关闭的资源，即使停在提示符也应先关闭，或明确选择中止任务与终端。正常停止失败时，恢复页提供说明和需明确确认的强制中止；默认流程不会静默强杀工具进程。

## 限制

- DSH 工具权限、文件版本保护及网络限制继续生效。文件版本冲突应重新读取并检查差异，不绕过保护。
- Windows 子进程、项目依赖和第三方插件兼容性取决于具体任务环境；错误需按具体命令归因。
- Windows 受限环境下，部分 Node 测试或构建命令会因子进程输出管道返回 `spawn EPERM`，实际测试可能尚未运行。执行记录可为有完整原命令与工作目录的记录准备一次性授权请求；只追加草稿，发送后仍须原生审批。批准仅作用于该命令，不改变默认权限；拒绝或取消后保持停止。
- 执行记录只包含 DSH 已保存的内容。上游未保存或已截断的输出无法在此恢复。
- 写入路径列表不等于完整 Git 差异；命令行修改、删除、重命名和人工已有改动要在代码变更中检查。
- 第三方侧栏的自动激活、预览和终端能力受其设置及依赖影响。受浏览器检查器或策略拦截的预览不能直接归因为产品缺陷。

运行时与插件版本统一见 [config/plugins.json](../config/plugins.json)；依赖和扩展规范见 [PLUGINS.md](PLUGINS.md)。
