# 当前现状与维护入口

DSH-PX 是面向本台 Windows 电脑的 Agent 产品。版本以根 `package.json` 为准；本轮维护版为 re.0.10.1。日常入口是原安装程序，开发与验收使用独立数据目录。

## 运行边界

| 项目 | 当前事实 |
|---|---|
| Agent 核心 | DSH 0.1.5-rc.2，执行、模型、权限、会话、子 Agent 与后台任务均由它负责 |
| 随附 Node | 24.16.0；开发 Node 要求 ≥24 |
| 桌面 | Electron 44.4.5；负责窗口、托盘、进程生命周期与应用更新 |
| 原安装 | `%LOCALAPPDATA%/Programs/dshpx-test/DSH-PX` |
| 原数据 | `%APPDATA%/dsh-px/dsh-home`；模型凭据与会话不会放进发布包 |
| 本机入口 | 原生 DSH 在 3080，已安装 DSH-PX 在 3081；两者独立 |
| 开发入口 | `npm run dev` 默认 `%APPDATA%/dsh-px-development`、3100；可显式覆盖环境变量 |
| 本轮 QA | `%APPDATA%/dsh-px-qa-re10`、3099；只保存验收数据 |

## 能力和所有者

| 用户看到的能力 | 实现来源 | 当前边界 |
|---|---|---|
| 模型、对话、工具、审批、计划、会话历史 | 原生 DSH | 核心行为不在 Electron 中重造 |
| 文件、编辑器、终端、Git、后台任务拓扑 | dsh-better-sidebar | 遵守原有启停配置；终端入口复用原生右侧栏 |
| 会话标签、引用批注、产物汇总、定时管理 | dsh-px-workspace | 定时任务仅在应用运行时投递；批注显式加入草稿 |
| 工作记录和执行证据 | dsh-px-taskflow | 工具正常返回不等于业务验证通过；输出按需分页读取 |
| 本机诊断和工作区入口 | dsh-px-workbench | 诊断与 Agent 共用原生网络服务 |
| 版本信息和安装状态 | dsh-px-updater + 桌面更新器 | 查询、接收、下载、安装分别呈现，不把上游核心版本当桌面可升级版本 |
