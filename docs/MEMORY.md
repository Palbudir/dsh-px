# 人格、记忆与工作账本

在工具栏打开“人格与记忆”，可以创建并选择当前会话的人格。每个人格保存自己的名称、职责与协作方式、记忆开关及记忆条目。新人格从空记忆开始，不复制其他人格的内容。

## 人格选择

人格与 DSH 的标准、创造等能力模式分别管理。人格改变协作方式，模型、工具和权限仍由原生会话控制。切换或编辑从下一轮生效，不改变正在运行的一轮。选择随会话保留；新建普通会话使用默认助手，分叉会话继承父会话的人格选择。

删除人格会同时删除其记忆，使用它的会话从下一轮恢复默认助手；已有会话正文保留。切换人格不会删除历史消息，因此不能把同一会话内的角色切换当作历史隔离。需要完全不同的聊天背景时，请新建会话。

## 保存和使用记忆

可以在面板中写入、编辑或忘记条目，也可以明确告诉 Agent：“记住本目录使用 pnpm”“修改之前的约定”“忘记这条记忆”。Agent 使用 `persona_memory` 工具读取当前版本后保存变更。

- **本目录**：仅此人格在相同规范化工作目录中使用；暂不自动合并 Git worktree 或不同目录。
- **此人格通用**：此人格在不同目录的会话中均可使用。
- 每条最多 2000 字，每个人格合计最多 8000 字，最多 40 条；人格总数最多 30 个。
- 关闭记忆后，从下一轮起停止向模型提供这些条目，记忆数据保留。
- 两个窗口同时修改时，旧版本提交会被拒绝，避免静默覆盖。刷新记录后核对再保存。

这一版只保存明确添加的记忆，不在后台自动提炼全部历史，不增加额外记忆模型调用。保存的条目从下一轮开始提供给 Agent。条目是参考资料，最新用户要求优先；版本、环境等易变事实仍需要核实。表单中的未保存内容不等于已记住，关闭或切换会话前请保存。

数据保存在 DSH_HOME 的 `storages/dsh-px-memory/memory.json`。使用临时文件、同步落盘及原子替换；读取损坏文件时不覆盖原件，面板显示错误，普通原生会话仍可继续。迁移机器时应与 DSH 数据一起备份，不提交到项目代码仓库。

## 长会话工作账本

“执行记录”中显示当前工作账本：目标、阶段进展、关键约束、决定与经验、下一步及执行证据引用。多步骤工作时，Agent 在重要进展、需求变化或遇到阻碍后通过 `task_checkpoint` 更新；也可以直接要求“保存当前工作账本”。简单问答不要求记录。

账本随原始会话工具记录保存。压缩改变模型可见历史时，PX 会重新提供最近保存的账本快照；它不依赖压缩摘要是否仍记得那份笔记。最近保存的用户要求会作为有界预览一并提供，较长内容可能截断。未保存进账本的细节仍依赖原生历史、摘要或后续读取，不能保证无限次压缩后完全无损。

`task_review` 读取账本和执行摘要；`task_evidence` 根据真实执行编号分页读取输出，不重新运行命令。记账前读取最新 checkpoint 序号可以防止覆盖已变更的记录。已有旧格式 checkpoint 继续可读。

账本不是另一套 goal、todo 或 job 调度器，也不是后台执行授权。用户新要求、原生目标和实际任务状态优先。工具“已返回”不等于测试通过；账本之后有新要求或操作时，面板提示重新核对。旧提交的测试结果不能证明新提交也通过。

## 更新与兼容

“人格与记忆”是独立的可选功能包。新客户端以 Pack 声明的清单管理功能包：首次出现的新功能可随升级安装，用户已经卸载的功能不会因此复活。自定义安装声明和禁用选择保留。较早的五功能包客户端需要先安装配套的新 Desktop；独立 Web 使用对应 Pack。

插件关闭不会删除记忆或账本。恢复插件后可以继续读取；未启用插件时，Agent 只使用原生 DSH 提供的上下文与工具。
