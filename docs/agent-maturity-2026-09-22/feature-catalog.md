# 100 项功能规划

基线：2026-09-22，DSH-PX re.0.7。这是待办池，阶段表示依赖与投资顺序，不是全部承诺交付日期。字段定义与首批排期见 [主报告](README.md)。[交互浏览](index.html) · [原始数据](feature-backlog.json)

重要程度 P0–P3：P0 为当前已确认的严重阻塞或数据风险，本次未确认 P0；P1 核心可用性；P2 高价值增强；P3 可选。实用/难度/适配均为 1–5，难度越高越难。人日为单项粗估，含实现与基本验收，不含等待上游；存在共用工作，不能机械相加。
